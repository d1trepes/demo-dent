# Дизайн — «Ясень» (утверждено 03.11.2026, чат 2)

Значения в коде — только из `styles/tokens.css`. Новые решения дописываем сюда.

## Решения, которые меняют паспорт §10
- Акцент — **синий кобальт и белый** вместо тёплой палитры (решение дизайнера). Не больничный голубой, без бирюзы и градиентов.
- «3D» импланта — **3 отдельные картинки** (коронка, абатмент, винт), разъезжаются при скролле. Не WebGL: ~200 КБ, работает и на мобильных. При `prefers-reduced-motion` — собранное состояние без анимации.
- «До/после» не делаем (38-ФЗ ст. 24). Вместо него слайдер-сравнение **«снимок КТ → цифровой план имплантации»**.

## Референсы
- SmileDent (Behance 255692565): контраст антиквы капслоком и курсива, подписи секций «(01) О клинике», строки-направления на всю ширину, вертикальная типографика со звездой, орбита «Почему мы», карусель врачей «большая + маленькие», форма поверх синего подвала с контурным словом.
- DENTAX (Behance 253115247): имплант в разборе с выносками, шаги 01–04 лесенкой, карточки отзывов.
- Whitebloom (Behance 233753527): огромное слово за фото врача на первом экране, плашка рейтинга, мастер записи (календарь + врачи со слотами), слайдер-сравнение.
- Не копируем один в один и не берём: зелёный/бирюзу, «до/после», стоковые улыбки крупным планом, алмазные зубы.

## Шрифты (вариант A, Google Fonts, кириллица)
- Заголовки: **Cormorant Garamond** — прямое капслоком для крупных слов, *курсив* для «рукописных» вставок («*Клиника,* где цена известна заранее»).
- Текст и интерфейс: **Manrope** (400/500/600/700).
- Не используем: Inter, Onest.

## Фото
- Единая серия: славянская внешность (Екатеринбург), белые халаты/медформа, светлый интерьер с синими деталями, мягкий дневной свет, один и тот же цветовой грейд.
- У каждого человека своя деталь (очки, веснушки, седина на висках, родинка, серьги-гвоздики, лёгкая щетина), естественная кожа, спокойные улыбки, без «пластика».
- Нельзя: крупные планы белоснежных улыбок, «ИИ-вид» (идеальная симметрия, глянцевая кожа, лишние пальцы), надписи и логотипы на фото.
- Формат — `.webp`, заданные размеры, ленивая загрузка (кроме первого экрана).

## Главная — блоки
1. Первый экран: огромное «ЯСЕНЬ» за вырезанным фото врача, синяя плашка с заголовком, кнопки «Записаться» / «Острая боль — приём сегодня», чипы ближайшего времени по филиалам, плашка рейтинга. Запасной вариант, если слово не понравится: фото врача в синей карточке со скруглением, слово меньше.
2. Направления: крупные строки на всю ширину, hover — заливка синим + фото + цена «от» + стрелка. На мобильном — аккордеон. Без бегущей строки.
3. Манифест «Цена известна до начала лечения»: вертикальная типографика со звездой и пунктиром, карточка плана лечения.
4. Имплантация: имплант в разборе при скролле, выноски, тизер калькулятора, рассрочка, `<Contraindications />`.
5. «Почему мы» — орбита: 6 фактов (план с суммой, выходные, детский кабинет, рассрочка без переплаты, КТ, справка для вычета). Без «без боли» и «гарантий».
6. Путь пациента 01–04: Запись → Консультация и КТ → План с суммой → Лечение.
7. Врачи: большая карточка + маленькие, клик меняет местами.
8. Детям (Академический).
9. Слайдер «КТ → цифровой план».
10. Отзывы: рейтинги площадок + карточки разной высоты (про сервис).
11. Филиалы.
12. Пациентам: вычет, рассрочка, документы — плитки разного размера.
13. Форма «Перезвоните мне» поверх синего подвала с контурным «Ясень».

Общий приём: подпись секции «(04) Врачи» мелко над заголовком.

## Компоненты
- Шапка + мобильное меню, подвал, нижняя панель «Позвонить | Записаться», cookie-баннер.
- `<Contraindications variant="banner|inline" />` — заметная плашка, ≥ 5% площади рекламного блока.
- В чате 2A: кнопки (primary / outline / ghost, стрелка ↗), чипы слотов, подпись секции, чекбокс согласия.

## Анимации
Появление блоков, переходы, отклик кнопок, медленное вращение орбит, разъезд импланта. Без параллакса на всё и бегущих строк. Всё отключается при `prefers-reduced-motion`.

## Доступность
Контраст AA, видимый фокус, кнопки ≥ 44 px, формы с подписями.
