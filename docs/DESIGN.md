# Дизайн — черновик (чат 1)

Значения — только из `styles/tokens.css`. Сейчас там заглушки; в чате 2 предложить 2 варианта палитры и шрифтов и утвердить с дизайнером.

## Направление (паспорт §10)
- Тёплый, спокойный, много воздуха, крупная типографика, человеческие фото. Противоположность демо 1 «Пролёт».
- Светлый тёплый фон (не белый), один глубокий основной цвет, один тёплый акцент для кнопок записи. Без больничного голубого и бирюзы.
- Заголовки — гуманистическая антиква или мягкий гротеск, текст — спокойный гротеск. Кириллица обязательна.
- Карточки разной формы и размера, умеренные скругления. Мастер записи — визуальный центр.
- 3D: один объект (имплант в разрезе), лениво, ≤ 500 КБ; на мобильных и `prefers-reduced-motion` — постер.
- Анимации сдержанные. Мобильная версия сначала (375 px).
- Нельзя: фиолетово-голубые градиенты, эмодзи, зубы-маскоты, стоковые улыбки, одинаковые карточки «иконка в кружке».

## Компоненты (есть в каркасе, без вида)
- Шапка + мобильное меню, подвал, нижняя панель «Позвонить | Записаться», cookie-баннер.
- `<Contraindications variant="banner|inline" />` — заметная плашка, ≥ 5% площади рекламного блока.

## Доступность
Контраст AA, видимый фокус (`--color-focus`), кнопки ≥ 44 px (`--tap`).
