# Чат 5А — «О клинике», документы и 3 текстовые юр.страницы (десктоп)

Сначала прочитай `docs/prompts/_common.md` — общие правила и порядок сдачи.

## Что сделать

1. **`/o-klinike/`** — о клинике + обязательные сведения.
   - Верх как у `/uslugi/` и `/akcii/`: `h1` (Prata, `--display-2`), lead (17–18 px, muted, max 760px). Тексты — новый `data/about.json`.
   - Блок «О клинике»: 2 абзаца позиционирования (`clinic.json → positioning`, `foundedYear`) + 2 фото из `public/images/branches/extra-01.webp`, `extra-02.webp` (прямоугольники со скруглением `--radius-md`, без листьев). Новых фото не нужно.
   - Раздел `id="svedeniya"` «Сведения о медицинской организации» (на него уже ведёт подвал): белая карточка `--radius-lg`, строки «подпись — значение» без пунктиров, разделитель 1 px `--color-line`. Поля: полное и сокращённое название, ОГРН, ИНН, КПП, юр.адрес, руководитель, адреса филиалов и режим (`branches.json`), телефон, почта, лицензия (номер, дата, орган, ссылка на реестр), перечень работ по лицензии (`licensedWorks`), контролирующие органы (`authorities`: название, роль, адрес/телефон если есть).
   - Сводная таблица врачей (требование 118н): ФИО, специальность, образование, сертификат/аккредитация (номер, срок), филиал, график. Данные — `doctors.json`. ФИО — ссылка на `/vrachi/<slug>/` (страница появится в 5Б). Таблицу сделать компонентом, чтобы потом переиспользовать.
   - В конце — ссылка-кнопка (secondary) «Документы клиники» → `/o-klinike/dokumenty/`.

2. **`/o-klinike/dokumenty/`** — список документов.
   - Тот же верх. Список из `legal.json → clinicDocuments`: белые строки-карточки «название — PDF, скачать», hover кобальтом как строки прайса. Если файлов в `public/docs/` нет — создать одностраничные PDF-заглушки с текстом «Демо-документ. Клиника вымышлена» (скриптом, один раз) и учесть basePath через `asset()`.
   - Отдельной группой — ссылки на 3 текстовые страницы: политика, согласие на ПДн, согласие на данные о здоровье.

3. **`/privacy/`, `/soglasie/`, `/soglasie-zdorovye/`** — один шаблон `LegalDocView` для трёх страниц.
   - Тексты уже есть: `legal.json → docs` (`id`, `title`, `version`, `updatedAt`, `sections`). Слева узкая липкая колонка 312 px с оглавлением по `sections` (как `PriceAside` на `/ceny/`), справа текст в белой карточке, ширина строки ≤ 72ch, под заголовком «Редакция {version} от {updatedAt}».
   - Метаданные страниц — из того же JSON.

## Правила
- Данные только из `/data` через `lib/api.ts` (добавь `getAboutContent()`, `getLegalDoc(id)`, если их нет), типы в `lib/types.ts`, никаких строк в компонентах.
- `<Contraindications />` на этих страницах нет — только в подвале (DESIGN.md).
- Токены, кнопки, отступы — из `styles/tokens.css` и `components/ui`. Новые решения — одной строкой в DESIGN.md.
- Без `any`, без неиспользуемого кода, без длинных комментариев.
