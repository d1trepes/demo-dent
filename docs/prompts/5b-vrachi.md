# Чат 5Б — врачи: список и карточка (десктоп)

Сначала прочитай `docs/prompts/_common.md`.

## 1. `/vrachi/`
- Верх: `h1` «Врачи» + lead (тексты — новый `data/doctorsPage.json`).
- Слева липкая колонка 312 px (как `ServicesAside` на `/uslugi/`): фильтр по специальности (`doctors.json → specialties`, чипы со счётчиками) и по филиалу (Все / Центр / Академический), отдельный чип «Принимает детей» (`acceptsKids`). Фильтр пишется в адрес `?specialty=&branch=`, чтобы ссылки с других страниц открывали отфильтрованный список.
- Справа сетка 2 колонки: белая карточка — фото `photo` (портрет, `--radius-md`, object-position top, ленивое, с размерами), ФИО, специальность, стаж «Стаж N лет» (`experienceSince`, `formatYears`), филиалы, ближайший свободный слот («Ближайшее: завтра, 10:30» — из `getSlots` для этого врача на 7 дней вперёд, загрузка по `import()`). Внизу две кнопки: «Записаться» → `/zapis/?doctor=<slug>`, «О враче» → `/vrachi/<slug>/`. Вся карточка не ссылка (две кнопки).
- Пусто после фильтра — карточка «Нет врачей по фильтру» + «Сбросить».

## 2. `/vrachi/[slug]/` — 11 страниц, `generateStaticParams` из `doctors.json`
- Верх: слева большое фото (прямоугольник `--radius-lg`), справа ФИО (Prata), специальность, должность, категория, стаж, филиалы-пилюли, `about`, кнопка «Записаться к врачу» → `/zapis/?doctor=<slug>`.
- «Свободное время»: 7 дней чипами (как шаг «Время» в мастере, переиспользуй его стили/компоненты) → слоты выбранного дня; клик по слоту → `/zapis/?doctor=<slug>&branch=<id>&slot=<iso>`. Если мастер не умеет `slot=` — добавь в `components/booking/init.ts` предзаполнение слота (шаг «Контакты»), не ломая остальные ветки.
- «Образование и квалификация» (обязательная информация, 118н): `education` и `certifications` (номер, дата, срок) — строками «подпись — значение», как на `/o-klinike/#svedeniya` (переиспользуй компонент из 5А, если он есть).
- «Направления»: пилюли-ссылки на `/uslugi/<id>/` по `directions` (только у которых есть страница).
- «График»: таблица по дням недели из `schedule` с филиалом.
- Внизу `CallbackCard` с текстами страницы (`source` = врач).
- Метаданные: «ФИО — специальность».
