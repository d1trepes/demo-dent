# Чат 6 — кабинет пациента (десктоп)

Сначала прочитай `docs/prompts/_common.md`. Можно делать в двух заходах: 6А вход + записи, 6Б план лечения + документы + напоминания.

## `/kabinet/vhod/`
- Белая карточка по центру: телефон (маска) → «Получить код» (`requestSmsCode`) → поле кода, подсказка «Демо: код 1234», таймер «Отправить ещё раз через 59 с» → `verifySmsCode` → `patientStore` «авторизован» → `/kabinet/`. Неверный код — ошибка под полем.
- Плашка «Демо-режим: SMS не отправляются».

## `/kabinet/` (без авторизации — редирект на `/kabinet/vhod/`)
- Шапка кабинета: «Здравствуйте, {имя}», кнопка «Выйти», кнопка «Записаться».
- Слева липкая колонка 312 px — оглавление разделов, справа разделы:
  1. **Записи**: ближайшие (из `patient.json → appointments` + созданные в мастере записи из `adminStore`/`bookingStore`): дата, время, врач с фото (`Avatar`), услуга, филиал. Действия: «Перенести» — раскрывает выбор слота (переиспользуй `StepTime`/его стили) → `rescheduleAppointment`; «Отменить» — подтверждение → `cancelAppointment`. Статус меняется и в `/admin/` (общий стор). Прошедшие — свернуты.
  2. **План лечения**: `getTreatmentPlan` — 4 этапа ветвью `PlanBranch` или строками: этап, врач, сумма, оплачено/осталось, итог и остаток крупно кобальтом. «Оплатить этап» → модалка-заглушка → `payPlanStage` → статус «Оплачено». Можно ссылку «Оплатить в рассрочку» → `/rassrochka/`.
  3. **Документы**: `getDocuments` — строки как на `/o-klinike/dokumenty/` (PDF-заглушки), + «Заказать справку для вычета» → `/vychet/`.
  4. **Напоминания**: переключатели SMS / Telegram / MAX, за 24 ч и за 2 ч → `updateReminderSettings`, тост «Сохранено».
- Никакой медкарты, снимков, диагнозов. Persist `patientStore` — только в try/catch (`safeStorage`).

## Сдача
Коммит `chat-6: кабинет пациента`. Ссылки: `/kabinet/vhod/`, `/kabinet/`. Проверка руками: записаться в `/zapis/` → войти кодом 1234 → запись видна → перенести → отменить.
