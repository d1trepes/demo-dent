# Чат 7 — панель администратора (десктоп)

Сначала прочитай `docs/prompts/_common.md`.

## `/admin/` — один экран, без пароля
- Сверху плашка «Демо-режим: данные из этой сессии и примеры». Шапка сайта упрощённая или та же — как проще.
- Сводка 4 цифрами: новые записи, записи на сегодня, заявки на справки, обратные звонки (цифры кобальтом, без иконок в кружках).
- Вкладки: **Записи** · **Справки для вычета** · **Перезвоните мне**.
- **Записи**: таблица (`getAdminAppointments` + `adminStore`): дата/время, пациент (имя, телефон частично скрыт), услуга, врач, филиал, источник (`source.label` — «откуда пришла запись»), статус пилюлей. Фильтры: статус, филиал, дата. Действия в строке: Подтвердить / Перенести / Отменить → `updateAppointmentStatus`; меняется и в кабинете пациента. Новые записи из этой сессии — сверху с меткой «Новая».
- **Справки**: `getTaxRequests` + `adminStore`: ФИО, год, способ, филиал, статус (Новая → В работе → Готова → Выдана), смена статуса.
- **Перезвоните мне**: `adminStore.createdCallbacks` + моки: имя, телефон, страница-источник, статус (`CallbackStatus`).
- Справа (или по клику на запись) — **превью уведомления в Telegram**: карточка в стиле сообщения бота «Новая запись: Иванова А., профгигиена, 14 ноября 10:30, Центр. Источник: /akcii/» + кнопки «Подтвердить / Перенести» (неактивные, подпись «так приходит администратору»). Без логотипа Telegram — просто вид сообщения.
- Закрыть открытые вопросы PROGRESS.md про `/admin/` (ссылка с `/zapis/gotovo/`, `createdCallbacks`).

## Сдача
Коммит `chat-7: панель администратора`. Проверка руками: создать запись, заявку на справку и «Перезвоните мне» → все три видны в `/admin/` → смена статуса видна в `/kabinet/`.
