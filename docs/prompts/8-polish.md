# Чат 8 — мобильная версия, полировка, сдача

Сначала прочитай `docs/prompts/_common.md`. Большой чат — делать заходами по 2–3 страницы: 8А главная + шапка/подвал/нижняя панель, 8Б запись + услуги + цены + рассрочка + акции, 8В врачи + филиалы + вычет + юр.страницы, 8Г кабинет + админка, 8Д проверка и сдача.

## Мобильная версия (375 px, затем 768)
- Только медиазапросы в существующих `.module.css`, без новой разметки, где возможно. Нет горизонтального скролла, кнопки ≥ 44 px, поля 16 px, сетки в 1 колонку, боковые колонки 312 px — над контентом (фильтры — горизонтальные чипы со скроллом).
- Нижняя панель «Позвонить | Записаться» (`MobileBar`) на всех страницах, кроме мастера записи и кабинета; не перекрывает подвал и cookie-баннер.
- Главная: hero по макету дизайнера (2A-M — спросить макет, если его нет в `docs/mockups/`), видео импланта → статичный постер, до/после — свайп, врачи — горизонтальная лента.

## Полировка
- 404 в стиле сайта, мета-теги и OG-картинка (1200×630, генерировать не нужно — собрать из фото hero кодом или попросить у дизайнера), `noindex, nofollow` на всех страницах, `prefers-reduced-motion`, фокус видно, контраст AA.
- Пройти критерии готовности паспорта §11 и открытые вопросы PROGRESS.md: закрыть или перенести в HANDOFF.md.
- Lighthouse мобильный (здесь можно): Performance ≥ 85, Accessibility ≥ 90.
- Финальный `docs/HANDOFF.md`: все функции `lib/api.ts` с типами, что подключить (МИС, SMS, Telegram, ЮKassa), хранение ПДн в РФ, логирование согласий.

## Сдача
Коммит на каждый заход `chat-8x: …`. Финальный отчёт — по критериям §11 галочками.
