# Общие правила для промптов чатов 5–8

- Проект «Ясень», репозиторий `d1trepes/demo-dent`. Сначала прочитай только «Сейчас» в `docs/PROGRESS.md` и нужные места `docs/DESIGN.md` (`grep`).
- Экономия токенов (паспорт §13): файлы читать точечно (`grep`, `sed -n`), без скриншотов, headless-проверок и Lighthouse, без вопросов, если ответ есть в DESIGN.md. Сомнительное — одной строкой в «Открытые вопросы» PROGRESS.md.
- Чаты 5–7 — только десктоп; разметка такая, чтобы мобильная версия в чате 8 свелась к медиазапросам.
- Данные только из `/data` через `lib/api.ts` (многие функции уже есть — сначала `grep "^export" lib/api.ts`), типы в `lib/types.ts`, никаких строк в компонентах. В клиентских компонентах `lib/api.ts` — только через `import()` по действию.
- Визуальный язык — как у `/uslugi/`, `/akcii/`, `/ceny/`: верх `h1` Prata `--display-2` + lead muted; белые карточки `--radius-lg` на фоне `--color-bg`; hover — название и цена кобальтом; кнопки из `components/ui/Button` (primary / secondary); боковая липкая колонка 312 px, если нужен фильтр или оглавление. Листья — только в hero, ветке плана, до/после. Без иконок в кружках, эмодзи, градиентов.
- `<Contraindications />` в блоках страниц нет — только в подвале.
- Формы: react-hook-form + zod, маска телефона, `ConsentCheckbox` не отмечен по умолчанию, ссылки на `/soglasie/` и `/privacy/`, никаких свободных полей для жалоб. Данные никуда не уходят.
- Переиспользуй готовое: `CallbackCard`, `Avatar`, `PriceRow`, `PriceAside`, `PlanBranch`, `Option` и стили мастера записи. Не переписывай файлы целиком — точечные правки.
- Новые фото не нужны, если в промпте не сказано иное. Без `any`, без неиспользуемого кода, без длинных комментариев. Новые дизайн-решения — одной строкой в DESIGN.md.
- В конце: `npm run build` без ошибок и предупреждений TS → коммит `chat-<N>: <что сделано>` → 2–4 строки в журнал PROGRESS.md, статус в плане чатов, в «Сейчас» — следующий чат → отчёт 3–5 строк со ссылками на страницы `https://d1trepes.github.io/demo-dent/...`.
